# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for security problems.

Especially useful reports:

- Personal data reaching a website or AI model when the extension says it was redacted
- Ways for a web page to read the token vault or restored values
- MCP server reading files outside `PII_FIREWALL_ROOTS`

Missed detections (false negatives) are not security issues; please open a normal issue with a fake example.
